# High-performance engine (HP)

AXIS ships an opt-in **high-performance plane** behind `axis.engine.hp.enabled` — **default off**. Until the default flip (PR 10), production keeps today's path: JSON `/ws/live` → JS `Bar[]` objects → Lightweight Charts. Every HP flag is a capability *selection*, never a requirement: any browser must keep booting and painting with HP off or fallen back.

## Rungs

| Rung | Isolation | Transport | Series memory | Paint | Typical host |
| --- | --- | --- | --- | --- | --- |
| **HP-0** | any | JSON `/ws/live` (today) | JS objects `Bar[]` | Lightweight Charts Canvas 2D, main | current production |
| **HP-1** | any | AXB1 binary **or** JSON, decoded in the ingest worker | transferable `ArrayBuffer` copy to main | LWC `series.update` / window `setData` | iOS WebView, non-isolated tab |
| **HP-2** | `crossOriginIsolated` | AXB1 into SAB ring | hot SAB double-buffer + IndexedDB cold | LWC samples completed generations via copy-out of the visible range | Chromium desktop, Tauri, isolated Pages |
| **HP-3** | isolated preferred | same as HP-2/1 | same | WebGL2 instanced quads; LWC remains for scale chrome or full fallback | GPU without WebGPU |
| **HP-4** | isolated preferred | same | same | WebGPU instanced quads; float32 NDC only at this boundary | Chromium + Vulkan/Metal |

**Selection** (`selectHpRung` in `src/hp/capabilities.ts`): kill switch → HP-0; not opted in → HP-0; WebGPU with `gpu` ≠ `off` → HP-4; else WebGL2 → HP-3; else isolated → HP-2; else HP-1. A SAB allocation failure clamps the tab to HP-1 for the session (`sessionStorage` `axis.hp.rung`); the cap only ever clamps downward.

## Flags

| Key | Default | Meaning |
| --- | --- | --- |
| `axis.engine.hp.enabled` | unset / off | master opt-in |
| `axis.engine.hp.disabled` | unset | hard kill — wins over enable |
| `axis.engine.hp.gpu` | `auto` | `auto` / `off` / `webgl2` / `webgpu` |
| `axis.engine.hp.sab` | `auto` | `auto` / `off` (force the transferable copy) |
| `axis.hp.rung` (session) | — | last successful rung; clamps down after a failure |

## Isolation

SAB needs cross-origin isolation. Every static host ships the same pair — `public/_headers`, the Vite dev server, `docker/nginx.conf`, the PWA servers, and the offline shell — kept honest by `tests/sw-parity.test.ts`:

```text
Cross-Origin-Opener-Policy: same-origin
Cross-Origin-Embedder-Policy: credentialless
Cross-Origin-Resource-Policy: same-origin
```

**The pair isolates.** Chromium sets `crossOriginIsolated` only for COOP `same-origin`, so the capability probe now reads:

```js
crossOriginIsolated;       // true
typeof SharedArrayBuffer;  // "function"
```

COOP was `same-origin-allow-popups` (popup-safe but never isolating) until this flip. No AXIS surface depends on a popup opener, so the stricter policy costs nothing: the GitHub/GitLab device-flow popup is opened `noopener,noreferrer` (`ScriptLibraryPanel`) and the token arrives by Worker polling (`waitForDeviceToken`) — never via `window.opener`; the detachable editor and panel companion windows are same-origin (BroadcastChannel / direct DOM wiring) and stay in the same browsing-context group under `same-origin`. With `isolated === true` the rung matrix unlocks HP-2/SAB; a tab that still fails isolation (exotic host, SAB allocation denied) keeps the transferable copy and reads `hp · copy+gpu` or HP-1 — the probe stays the runtime source of truth.

## Transport: AXB1

- Canonical prices are **int64 ticks**: `decimalToTicks` / `priceToTicks` keep float64 and float32 out of the codec (`priceToTicks(0.00000012, 8) === 12n`).
- The AXB1 delta is 4-byte aligned with `TIP` vs `APPEND` opcodes and hashed payloads. Golden vectors in `tests/data/axb1-vectors.json` pin every frame shape, shared with the PYNE repo's `tests/test_axb1.py`.
- The PYNE engine emits binary `/ws/live` frames when `encoding=axb1` is negotiated (sister repo `pynescript`); the AXIS Worker relays non-text frames untouched (`worker/src/live-proxy.ts`).
- Decode runs off-thread in the ingest worker (`src/hp/workers/ingest.worker.ts`), engaged by `createLiveWsClient` (`src/hp/workers/host.ts`) only when HP is enabled — otherwise the stock JSON client is returned unchanged.

## Memory: SAB double-buffer + IndexedDB cold

- **Hot:** a generation double-buffer in a SharedArrayBuffer of fixed size `O(HOT_CAP)` — never `O(N)` — read through seqlocks; `Atomics.wait` on workers only (main polls via rAF + `waitAsync`).
- **Cold:** columnar pages over IndexedDB; the viewport page lives in the same SAB behind its own seqlock, so paging never perturbs the hot ring (`src/hp/memory/`).
- Chart sampling uses the copy-out (`src/hp/paint/copy-out-lwc.ts`): LWC remains the painter through HP-2.

## Paint: LWC, then the GPU rung

- Probe order (`probeRendererKind`): **WebGPU → WebGL2 → LWC**. The `off` flag lands on LWC even where a GPU exists, and a forced mode never claims a backend the probe did not find.
- The WebGL2 painter (`src/hp/render/webgl2-renderer.ts`) draws the viewport as one instanced call: one VAO, one 32-byte `VisualCandle` record per candle, a fragment shader that carves body + wick from a single quad. Float32 is **NDC-only** at this boundary (WebGPU has no float64); price ticks stay in the SAB.
- The factory is null-never-throws: any context or shader failure falls through to LWC instead of failing the page.
- **Status:** the stacked GPU overlay lands with `src/hp/render/gpu-overlay.ts` — a transparent WebGL2 canvas over the price pane's content area, fed from the HP-2 hot ring, engaging **only** on the forced `gpu=webgl2` rung (LWC paints candles translucent; stacking would composite darker, so `auto`/`off`/`webgpu` stay dormant). The ring is placed as the chart's **tail window** by identity (ring tail time = chart tail time → slot `j` is chart index `chartBars − hotCount + j`), so a short engine snapshot on a long REST chart paints the visible tail; a viewport reaching into colder history clears (cold paging is not wired). PaneManager is not touched and LWC keeps painting every candle underneath — hiding LWC's candle series stays gated on production measurement (plan §14.2).

## HUD chip

Workers Manager → **Chart plane** shows the selected rung in plan format: `hp · sab+gpu`, `hp · copy+lwc`, or `json · lwc` (transport memory + painter). `json · lwc` is exactly today's path, so the default-off state reads truthfully. On an opted-in, cross-origin isolated Chromium with a GPU the chip reads `hp · sab+gpu`: the SAB hot ring feeds both the rAF copy-out and the stacked GPU overlay (the overlay itself still waits for the forced `gpu=webgl2` rung — selection is not wiring). The chip reports the *selection*.

## MCP observability

The HP flags are tab-local `localStorage` and isolation is a runtime property — neither crosses the sanitized app snapshot, so agents get two dedicated read-only capabilities (`src/mcp/hp.ts`):

- **`hp.get`** — flags (enable / kill switch / `gpu` / `sab`), the cross-origin isolation probe, the HUD chip verbatim, the session rung cap (`axis.hp.rung` after a SAB OOM), the **actual** hot-ring runtime (window bounds, `seq` / `closedUpto`, SAB bytes, `tailTime` vs `chartTailTime`, and the tail-identity placement the GPU overlay guard enforces), the wire state, the overlay canvas's DOM state, and a verdict: `kill` / `off` / `awaiting` / `copy` / `fallback` / `degraded` / `misaligned` / `live`.
- **`hp.sample`** — a bounded window (100 ms–10 s, default 1 s) of *movement*: ring `seq` delta (ingest publishes actually landing), `closedUpto` progress, rAF frame cadence, and the chart's append/tail deltas. A snapshot says "the ring is aligned"; the sample says "the ring is moving".

Both are pure reads — no flag writes, no wire start, no SAB allocation, no secrets.

## Invariants

- Kill switch wins over enable, and the flag-off path stays byte-identical to today's JSON client.
- int64 ticks never cross the GPU boundary; float32 appears only after NDC mapping.
- `Atomics.wait` is worker-only; main-thread waiting is rAF/`waitAsync`.
- AXIS is independent of TradingView® and ships its own painter; Pine Script™ evaluation runs through PYNE, never through a TradingView product API.
