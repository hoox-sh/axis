# Feature atlas

## Abstract

This atlas is a **path index** for AXIS. Use it to jump from a product feature to the code that implements it. Prefer Solid product paths over legacy static shell files.

## Conceptual model

```mermaid
mindmap
  root((AXIS))
    Plugins
      sources
      streams
      engines
      storage
      loader
    AXIS
      chart
      editor
      ui
      store
    Worker
      run
      keys
      scripts
      DO
    DevOps
      vite
      pages
      ci
```
